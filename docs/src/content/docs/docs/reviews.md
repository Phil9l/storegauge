title: Reviews
description: Triage, translate, answer, and export reviews from Apple and Google.
---

Reviews are grouped into **Needs Reply**, **Acknowledged**, and **Answered**. Reply from either store, edit existing replies where the provider permits it, or acknowledge feedback that does not need a public response.

## Translation

StoreGauge detects the review language and uses Apple’s Translation framework on-device. The target language follows your system by default, or you can choose another in Settings.

- Turn on automatic translation or translate individual reviews.
- Switch between original and translated text.
- Cached translations are scoped to the selected target language.
- No review text is sent to a StoreGauge translation service because no such service exists.

## Copy and export

Copy the currently visible original or translated review from its action bar. CSV export keeps review text and metadata in a portable local file.

## MCP visibility

If MCP sharing is enabled, review ratings and triage state can be included in the sanitized snapshot. Review text, reviewer names, and response text have a separate privacy toggle and can be excluded.
