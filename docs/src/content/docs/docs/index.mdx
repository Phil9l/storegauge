## How StoreGauge handles your data

StoreGauge has no sign-in or hosted service. Store credentials go to the Mac or iPhone Keychain, imported product data stays in SwiftData, and optional Mac MCP sharing uses a separate credential-free snapshot. See the [privacy page](../privacy/) for the complete data-flow description.

## Requirements

- macOS 15 or later
- iOS 18 or later for the iPhone client
- An App Store Connect account with access to create a Team API key, a Google Play developer account, or both
- Xcode 26.3 or later only when building from source
