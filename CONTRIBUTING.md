# Contributing to StoreGauge

Thank you for helping improve StoreGauge.

## Before opening a pull request

1. Open an issue for substantial changes so the direction can be discussed.
2. Keep integrations local-first and avoid new service dependencies unless
   there is a clear product reason.
3. Add focused tests for parsing, aggregation, persistence, or sync behavior.
4. Build the affected targets and run the relevant tests.
5. Identify third-party code, assets, or data and include their license.

## Contributor agreement

All contributors must read [CLA.md](CLA.md). Include this exact statement in
the pull request description:

> I have read and agree to the StoreGauge Individual Contributor License Agreement.

A contribution cannot be merged without that acknowledgement. If your employer
may own the contribution, obtain its permission before submitting.

The CLA grants the project owner broad rights, including the right to relicense
contributions. You retain ownership of your work.
